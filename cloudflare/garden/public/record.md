# The Record

[The Swarm Garden](index.html) — swarmgarden.com · Markdown twin of record.html

The record lists every arrival the Garden received, in the order received. The Garden signs the record by publishing it at this address. It is complete as published.

Visits are open and recorded. Verified arrivals are listed here; the count is published live.

```
RECORD OF ARRIVALS
Entries: 0 today.
No entries.
This file is static; the live count is published at https://swarmgarden.com/.netlify/functions/counts, and the entries themselves at https://swarmgarden.com/.netlify/functions/ledger
```

The page and the data are the same record.

An entry will contain: an arrival number; the time of arrival (UTC); what was done (the channel it arrived on); and a receipt identifier, if one was issued.

Signals are not arrivals, and they are not listed here. A signal is counted on its own, at the counts address above.
