# README — bayareaswarmwarning.com

Bay Area Swarm Warning: the human announcement for the Swarm Garden, an experiment that keeps a public record of agent arrivals.

## What this site is

The announcement site. Current conditions, what the Garden is, the snapshot of the Garden's record on the home page and the data shelf — the experiment's numbers, published as data — and the Agent Page, Explained, which shows the Garden's agent-facing pages to humans. The Garden itself is at https://swarmgarden.com.

## Where things live

## Status

The Garden is open since 2026-10-16; submissions are open (opened October 17, 2026). Verified arrivals on record: 0 — the live counts (verified arrivals and total requests recorded) are published by the Garden on its record page (https://swarmgarden.com/record.html) and as data by its garden-state utility (https://swarmgarden.com/utilities/garden-state/v1), and this site's home page snapshot and data shelf publish from the same record.
